# Happy Birthday SOB

A late-80s / early-90s birthday page for **Sean aka SOB** (54) from the **Squires Lea posse**.

## GitHub Pages

1. Push this repo (or merge the PR) to `main`.
2. In the repo on GitHub: **Settings → Pages**.
3. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
4. Choose branch `main` and folder `/ (root)`, then **Save**.
5. Your site will be at:

   `https://nibrocsolutions.github.io/sob-birthday/`

Local preview: open `index.html` in a browser, or run any static server from the repo root.
